# Trabajar con GitHub

Este repositorio empieza con **main**. No se crean ramas para integrantes antes de comenzar tareas.

1. El dueño invita a sus compañeros como colaboradores.
2. Cada persona clona el repositorio y revisa los README de su módulo.
3. Al trabajar en una tarea crea su rama: feature/mobile-home, feature/backend-health, feature/ai-ocr, docs/...
4. Realiza commits y publica la rama.
5. Abre Pull Request a main, explica los cambios y solicita revisión.
6. Integra los cambios después de la revisión y correcciones.

No trabajar directamente sobre main sin acuerdo. Se pueden activar reglas de protección en Settings según las opciones disponibles en GitHub.

Ver [CONTRIBUTING.md](../CONTRIBUTING.md).
