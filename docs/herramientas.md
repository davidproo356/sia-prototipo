# Herramientas de desarrollo

| Herramienta | Para qué se utilizará |
| --- | --- |
| Git + GitHub | Control de versiones, ramas, revisión y Pull Requests |
| VS Code | Editor recomendado para todos |
| Docker Desktop + Docker Compose | Base de datos y servicios locales |
| Node.js, npm y Expo | Aplicación móvil React Native |
| Android Studio / Android SDK | Emulador y herramientas Android |
| JDK 21 y Maven | API Spring Boot |
| Python 3.12 y entorno virtual | Servicio IA FastAPI |
| Postman o Bruno | Solicitudes y pruebas de APIs |
| DBeaver (opcional) | Inspección de la base de datos |
| Figma (opcional) | Diseño y evaluación de pantallas accesibles |

**No todos deben instalarlo todo**: cada compañero usa las herramientas pertinentes a su módulo. Docker **no** ejecuta Android. Antes de instalar dependencias definitivas hay que comprobar sus versiones y licencias.
