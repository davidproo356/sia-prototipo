# Alcance de SIA — prototipo académico

## Usuario y demostración
Carlos es un personaje adulto mayor con baja visión que desea cobrar su pensión: necesita reconocer el panel de una ticketera, identificar un ticket ficticio A32, esperar el anuncio de ventanilla 6 y desplazarse en un espacio que puede tener obstáculos dinámicos. El prototipo deberá ofrecer una alternativa al micrófono en ambientes ruidosos.

## Fases
- **Fase 0 — Actual:** estructura del repositorio, dependencias preliminares, Docker y documentación. **Ninguna función implementada**.
- **Fase 1:** pantallas accesibles y recorrido narrativo **simulado y rotulado**.
- **Fase 2:** integración entre app, API y servicio IA mediante contratos JSON.
- **Fase 3:** experimentación con OCR, cámara, audio y YOLO sobre datos autorizados.
- **Fase 4:** navegación interior experimental con validación de condiciones, errores y seguridad.

## Fuera del alcance de esta entrega
Transacciones bancarias, acceso a sistemas del banco, reconocimiento facial, entrenamiento completo de IA, navegación autónoma segura y despliegue para clientes reales.

**No presentar el recorrido narrativo como sistema de seguridad o prevención de accidentes.**
