# Primeras tareas sugeridas para tres integrantes

No son asignaciones fijas ni ramas creadas; la distribución la acuerda el grupo.

### Frente móvil
Preparar punto de entrada Expo, navegación y primeras pantallas accesibles, permisos, cámara y evaluación con TalkBack; distinguir interfaces simuladas de funcionalidad real.

### Frente API + BD
Crear la clase principal Java, servicio Spring Boot, health check, contratos, validación y solo las tablas justificadas por casos de uso; documentar migraciones con Flyway.

### Frente IA + integración
Preparar FastAPI, endpoint de salud, contrato de observaciones, mocks identificados, selección de OCR/YOLO, licencia y pruebas de errores.

### Tareas compartidas
Acordar contratos, actualizar READMEs, revisar PRs, privacidad, seguridad de movilidad y material de presentación del prototipo.
